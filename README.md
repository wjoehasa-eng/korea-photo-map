# 🗺️ 여행 사진 지도 (korea-photo-map)

대한민국 **250개 시·군·구** 행정구역 지도에 다녀온 곳의 여행 사진을 채워 넣는 웹앱입니다.
사진은 서버로 보내지 않고 **이 브라우저(IndexedDB)에만** 저장됩니다.

- 라이브: <https://wjoehasa-eng.github.io/korea-photo-map/>

## 기능

- **시·군·구 지도**: 통계청(KOSTAT) 2018 행정구역 경계 250개 폴리곤(제주·울릉도·독도 포함)
- **확대/축소·이동**: 마우스 휠, 버튼, 모바일 핀치·드래그, 전체 보기 초기화
- **찾기**: 시·도 빠른 이동 칩 + 지역 이름 검색(예: `고창`, `강남`)
- **사진 채우기**: 사진이 등록된 지역은 행정구역 모양 그대로 대표 사진이 꽉 차게 클리핑되어 표시
  (`<pattern patternTransform>` + `<image preserveAspectRatio="xMidYMid slice">`)
- **지역별 사진 묶음**: 지역을 누르면 우측 패널(데스크톱) / 하단 시트(모바일)로 그 지역의 여행 기록이 열립니다
  - 여행 기록 추가: 날짜·제목·메모 + 사진 여러 장
  - 사진 추가·삭제, 대표 사진 변경, 라이트박스 크게 보기, 기록 삭제
- **진행률**: 상단 `✈️ N / 250 정복 (XX%)`
- **저장·백업**: 사진 자동 리사이징(장변 1500px, 썸네일 520px) 후 IndexedDB 저장, JSON 백업 내보내기/불러오기
- **예시 채우기**: 실제 사진 없이 캔버스로 그린 일러스트로 20곳을 채워 미리보기(언제든 삭제 가능)

## 구조

```
index.html            화면 마크업
styles.css            디자인(파스텔 여행 앨범 톤)
js/app.js             앱 로직(패널·폼·백업·검색·진행률)
js/map.js             SVG 지도 렌더링·줌/팬·사진 패턴
js/store.js           IndexedDB 저장소, 사진 압축, 백업
js/sample.js          예시 일러스트(캔버스 벡터 아트)
data/regions.json     투영된 SVG path + 라벨 좌표(약 266KB)
tools/build_map_data.py  행정구역 TopoJSON → regions.json 변환
tools/verify.py       Playwright 검증(데스크톱 1280 · 모바일 390)
```

## 데이터 출처

- 행정구역 경계: **통계청(KOSTAT) 2018 시·군·구** — <https://github.com/southkorea/southkorea-maps> (kostat/2018)
- 지도는 WGS84 경도를 위도 보정한 단순 원추 투영으로 SVG 좌표(1000px 기준)로 변환했습니다.

## 개인정보

이 저장소에는 개인정보·실제 사진·개인 지명 등이 전혀 포함되어 있지 않은 빈 껍데기 상태입니다.
모든 사진과 기록은 사용하는 기기의 브라우저 저장소에만 남고, 다른 기기로 옮길 때는 백업 파일(JSON)을 직접 내려받아 불러옵니다.
