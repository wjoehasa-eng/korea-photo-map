# 🗺️ 여행 사진 지도 (korea-photo-map)

대한민국 **250개 시·군·구** 행정구역 지도에 다녀온 곳의 여행 사진을 채워 넣는 웹앱입니다.
사진은 서버로 보내지 않고 **이 브라우저(IndexedDB)에만** 저장됩니다.

- 라이브: <https://wjoehasa-eng.github.io/korea-photo-map/>

## 기능

- **시·군·구 지도**: 통계청(KOSTAT) 2018 행정구역 경계 250개 폴리곤(제주·울릉도·독도 포함)
- **확대/축소·이동**: 마우스 휠, 버튼, 모바일 핀치·드래그, 전체 보기 초기화
- **찾기**: 시·도 빠른 이동 칩 + 지역 이름 검색(예: `고창`, `강남`)
- **사진 채우기**: 사진이 등록된 지역은 행정구역 모양 그대로 대표 사진이 꽉 차게 클리핑되어 표시
  (`<pattern patternTransform>` + `<image preserveAspectRatio="xMidYMid slice">`)
- **지역별 사진 묶음**: 지역을 누르면 우측 패널(데스크톱) / 하단 시트(모바일)로 그 지역의 여행 기록이 열립니다
  - 여행 기록 추가: 날짜·제목·메모 + 사진 여러 장
  - 사진 추가·삭제, 대표 사진 변경, 라이트박스 크게 보기, 기록 삭제
- **진행률**: 상단 `✈️ N / 250 정복 (XX%)`
- **지도 대표 사진과 일기 대표 사진 분리**: 지역마다 지도에 칠하는 사진(`🗺️ 지도 대표`)과
  여행 기록마다의 대표 사진(`📖 일기 대표`)을 따로 정합니다. 새 여행을 남겨도 기존 지도 사진은 덮이지 않아요.
- **구글 드라이브 연동(선택)**: `⋯` → `☁️ 구글 드라이브 연동`에 Apps Script 웹앱 주소를 넣으면
  기록은 비공개 시트에, 사진은 내 드라이브 `사진` 폴더에 함께 보관되고, 다른 기기에서도 이어집니다.
  주소를 비우면 지금처럼 100% 이 기기 저장으로 돌아갑니다.
- **저장·백업**: 사진 자동 리사이징(장변 1500px, 썸네일 520px) 후 IndexedDB 저장, JSON 백업 내보내기/불러오기
- **예시 채우기**: 실제 사진 없이 캔버스로 그린 일러스트로 20곳을 채워 미리보기(언제든 삭제 가능)
- **설치(PWA)**: 안드로이드 크롬에서 `앱 설치` / `홈 화면에 추가`로 설치하면 주소창 없이 앱처럼 열리고,
  서비스 워커가 앱 셸을 미리 담아 두어 **신호가 없어도** 지도와 저장된 사진이 열립니다
- **모바일 조작**: 하단 시트는 손잡이를 아래로 끌거나 ✕·바깥 탭으로 닫히고,
  안드로이드 뒤로가기를 누르면 앱이 꺼지기 전에 열린 창부터 닫힙니다

## 구조

```
index.html            화면 마크업
styles.css            디자인(파스텔 여행 앨범 톤)
manifest.webmanifest  PWA 매니페스트(이름·아이콘·standalone·테마색)
sw.js                 서비스 워커(앱 셸 프리캐시 + 오프라인 대응)
icons/                앱 아이콘 PNG 192 · 512 · maskable 512
js/app.js             앱 로직(패널·폼·백업·검색·진행률·설치 안내)
js/map.js             SVG 지도 렌더링·줌/팬·사진 패턴
js/store.js           IndexedDB 저장소(여행·사진·지역 대표), 사진 압축, 백업
js/cloud.js           구글 드라이브(Apps Script) 연동·동기화
js/sample.js          예시 일러스트(캔버스 벡터 아트)
data/regions.json     투영된 SVG path + 라벨 좌표(약 266KB)
apps-script/          구글 드라이브 연동용 Apps Script 백엔드(선택, ID는 자리표시자)
tools/build_map_data.py  행정구역 TopoJSON → regions.json 변환
tools/make_icons.py   앱 아이콘 PNG 생성(Pillow)
tools/verify.py       Playwright 검증(데스크톱 1280 · 모바일 390)
tools/verify_pwa.py   PWA 검증(매니페스트·아이콘·서비스 워커·설치 가능성·오프라인)
tools/verify_cloud.py 드라이브 연동 검증(가짜 Apps Script로 업로드·내려받기·대표 사진·모바일 제스처)
tools/verify_sw_update.py 서비스 워커 업데이트 검증(옛 캐시 kpm-v2 → kpm-v3 교체·새 app.js 반영·오프라인)
```

## 설치(안드로이드)

1. 크롬에서 <https://wjoehasa-eng.github.io/korea-photo-map/> 열기
2. 주소창 오른쪽 `⋮` → **앱 설치**(또는 **홈 화면에 추가**), 앱 안에서는 `⋯` → **📲 앱처럼 설치**
3. 홈 화면의 🗺️ 아이콘으로 앱처럼 실행 — 주소창 없이 열리고 오프라인에서도 켜집니다

설치가 안 보이면 두 번 이상 방문한 뒤 다시 시도하세요(크롬이 설치 조건을 확인하는 데 잠깐 걸립니다).

## 데이터 출처

- 행정구역 경계: **통계청(KOSTAT) 2018 시·군·구** — <https://github.com/southkorea/southkorea-maps> (kostat/2018)
- 지도는 WGS84 경도를 위도 보정한 단순 원추 투영으로 SVG 좌표(1000px 기준)로 변환했습니다.

## 개인정보

이 저장소에는 개인정보·실제 사진·개인 지명 등이 전혀 포함되어 있지 않은 빈 껍데기 상태입니다.
모든 사진과 기록은 사용하는 기기의 브라우저 저장소에만 남고, 다른 기기로 옮길 때는 백업 파일(JSON)을 직접 내려받아 불러옵니다.
구글 드라이브 연동을 켜면 기록·사진이 사용자 본인의 비공개 시트·폴더에만 보관되며,
연동 주소(Apps Script 웹앱 URL)·시트 ID·폴더 ID는 이 저장소에 포함되지 않습니다.
`apps-script/Code.gs`는 `YOUR_SPREADSHEET_ID` · `YOUR_PHOTO_FOLDER_ID` 자리표시자만 둔 템플릿입니다.
